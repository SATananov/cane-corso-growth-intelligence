# Course Scope and Exploratory Visual Similarity Extension

## Core course-aligned project

The core of this project is the Cane Corso growth-intelligence workflow built from tabular growth records. This part is aligned with the course topics covered so far:

- Linear Regression, Regularization and Testing;
- Classification;
- Unsupervised Learning and Clustering;
- Feature Engineering and Time Series;
- data processing, model evaluation, documentation and responsible interpretation.

The project should continue to follow the course path. After the relevant lectures, the next natural additions are Dimensionality Reduction and MLflow.

## Exploratory visual extension

The image-based work is an optional extension, not the main course requirement. It explores whether a public dog-image dataset can support a small visual-similarity experiment among available large-dog classes.

The current lightweight image classifier is therefore best described as:

```text
an educational visual-similarity baseline over available public dataset classes
```

It should not be described as:

```text
a Cane Corso detector
a breed-proof system
a pedigree checker
a certification or registry authority
a veterinary diagnostic tool
```

## Why keep it

The extension is still useful because it demonstrates:

- responsible dataset selection;
- local-only image storage;
- train / validation / test split preparation;
- image feature extraction;
- classification metrics;
- careful limits around model interpretation.

It adds creativity and project growth while the main grading evidence remains the course-aligned growth ML workflow.
