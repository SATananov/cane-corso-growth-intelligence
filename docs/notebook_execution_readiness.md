# Notebook Execution Readiness

The notebooks are designed to be readable in order and to provide visible output when executed with **Run All** in Jupyter or VS Code.

Use the project virtual environment as the notebook kernel. Each notebook starts by locating the project root and printing a readiness message. Course topics that have not been covered yet are intentionally represented as reserved notebooks; they print a short note and will be expanded after the corresponding lesson.

The exploratory visual-similarity notebooks use local image data only when it is available. They do not require image files to be stored in the repository.
